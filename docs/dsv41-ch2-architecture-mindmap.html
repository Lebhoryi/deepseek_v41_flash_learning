2. Architecture（网络结构总览）
2.1 Overview 宏观结构▾
多模态 MoE Transformer图像+文本输入 → 自回归文本输出
40 层 = 20 因果编码器 + 20 解码器（CED）
每层：全局注意力 + SWA前 2 层仅 SWA；其余层两者皆备
参数与激活552B 主干 + 196B Engram；激活 8B prefill / 16B decode
核心组件栈DeepSeekMoE · CED · CSA2 · mHC · Engram · DSpark · FP4 KV▾
MoE1 共享 + 384 路由专家、top-6；保留 shared + fine-grained routed（DeepSeekMoE）
新增：模态感知无辅助损失负载均衡文本/图像 token 各自维护 expert 校正 bias：选专家用模态 bias，加权用原始路由分；每步独立更新 → 模态内均衡
2.1.1 多模态架构（视觉路径）▾
DeepSeek-ViT（从零训练）▾
2D-RoPE 替代绝对位置编码支持任意分辨率输入
线性 patch embedding 替代卷积为兼容 Muon 优化器
RMSNorm + SwiGLU向 LLM 设计对齐
3×3 pixel-unshuffle 下采样视觉 token 减少 9 倍，支持约 1344×1344 分辨率
MLP projector视觉特征映射到 backbone 隐藏维，插入图像 token 位置与文本联合处理
2.2 Causal Encoder-Decoder（CED）▾
动机agent 工作流大量 tool calls → prefill 频繁且 KV miss 时开销巨大；要砍 prefill 计算
灵感：YoCo上半个网络直接共享下半个生成的 KV
设计：全局 KV 由编码器末层投影▾
下 L/2 层 = 因果编码器正常计算 hidden state H_{L/2}
解码层 (l > L/2) 不再从自己的 H_l 算 KV改为：C_l = H_{L/2}·W_l^KV，Z_l = H_{L/2}·W_l^Z（层相关投影权重）
效果prefill 阶段只需计算前 20 层 即可获得整个解码器全局 KV → 计算近乎减半
SWA 保持逐层计算局部 K/V 仍来自当前层 H_l → 增加局部 KV 生成深度，但引入 replay 开销▾
Decoder SWA Bounded ReplaySWA 有效感受野远小于理论 n_win×L/2 → 只需 prefill 最后一个 n_win 段（细节见 3.2.2）
复杂度收益O(NL) → O(NL/2 + n_win×L/2) ≈ O(NL/2)（N ≫ n_win，整体减半）
2.3 Compressed Sparse Attention 2（CSA2）▾
长上下文三大乘法维度三者相乘决定 KV 存储与注意力成本▾
① entry 大小GQA 减 KV 头数；MLA 多头共享小 latent
② 序列维度每 m 个 token 压缩为 1 个 entry（V4 的 CSA/HCA）
③ 层维度跨层复用 cache 与选择（IndexCache / YOIO / HySparse）；但各自只覆盖部分维度
CSA2 = 三维度联合跨层共享 main KV + indexer K，允许复用 Top-K 索引；共享与复用解耦▾
简化的 compressor对比 CSA：去掉重叠源条目与绝对位置编码
简化的 indexerindexer K 直接由 main KV 投影得到（替代 CSA 从 hidden 的独立压缩路径）→ 实现/训练更简单
压缩比 1 = 不压缩的特殊情况
Q 注意力范围选出的 Top-K main KV + 层局部 SWA KV
2.3.1 跨层 KV 与索引复用（三种静态模式）每层共同点：都自算 Q 与 SWA KV；差异在 main KV / indexer K / Top-K 从哪来（Figure 4）▾
Full 模式（绿）自算 main KV + indexer Q + indexer K + 全新 Top-K —— 完整 CSA2 路径，职责等同 V4 的 CSA 层
Reindex 模式（黄+绿）复用最近 main KV 与对应 indexer K；只自算 indexer Q、重打分 → 产生新 Top-K（选择可随层变化，KV 仍共享）
Reuse 模式（红）复用最近 main KV + 最新 Top-K 索引；零 indexer 计算
与 CED 结合decoder 中 Full 模式的层，其全局 KV 由 H_{L/2} 投影而来；Reindex/Reuse 不变
收益共享 KV 省存储；复用索引省 indexer 计算；Reindex 兼顾"缓存共享 + 选择随层变化"
2.3.2 Hierarchical Sparse Indexer（分层稀疏索引器）仅用于 decoder；跨层复用后，剩余 indexer 仍要打分全量上下文 → 继续砍▾
第一个 Full 模式层（构建候选池）▾
① 全量打分扫描全部因果可见 main KV 位置，选自己的 Top-K
② blockwise 选块每块取位置最大 indexer 分，选分数最高的一批块
③ 候选池所选块覆盖的位置（例：2048 块 × 8 位置 = 16384 候选）> 最终 Top-K 集合
后续 Reindex 层只在候选池内打分选自己的 Top-K → 每 query 打分成本与上下文长度无关（常数）
Reuse 层不做新索引，直接用最新 Top-K
Training-aware后训练阶段引入，训练与推理使用同一搜索域，深 layer 在推理域下被优化
2.4 高效架构扩展▾
2.4.1 Single-Pass mHC（单遍超连接）▾
mHC 回顾（V4）n 条残差流：X_{l+1} = B_l·X_l + C_l·F_l(A_l·X_l)，系数 (A,B,C) = H(X_l)
V4 多核实现=3 个 kernel 顺序执行残差更新 → 系数预测 → 输入混合；激活内存流量 (4n+4)d，是理论下界 (2n+2)d 的 2 倍
单遍思路混合系数移位：本 block 用上一 block 的 A_{l-1} → 消除依赖，X_l 分块即算即用 → 单 kernel 融合
Mega-mHC kernel部署端：残差更新+输入混合+系数预测融合为 1 个 kernel，流量降到 (2n+2)d（理论下界）；并融入 pre-norm + FP8 转换
预训练仍用多核实现该移位仅改变各 block 应用的混合系数，实证性能损失可忽略
2.4.2 Engram（条件记忆模块，196B）▾
定位记忆与计算解耦；沿用原设计：tokenizer 压缩 + 多头哈希 + 上下文感知门控 + 多分支集成
两处修改① 去掉短因果卷积（收益不抵推理栈复杂度）；② 嵌入用 momentum + Sinkhorn 平衡更新（见 2.5）
配置两个模块均分 196B；n-gram 阶 {2,3,4}；8 个哈希头；每阶嵌入维 2048；每头索引表 ~16M（表大小取互异素数）；嵌入表与 K/V 投影均为 FP8
放置层 1 和 14（0-indexed），均衡训练 pipeline 各阶段的显存
推理优化确定性寻址 → 嵌入可从主机内存经后台 RDMA 预取，第一模块的预取与第一个 Transformer block 计算重叠
2.4.3 DSpark（投机解码）▾
总览半自回归草稿 + 置信度调度验证
草稿器3 个 Transformer block，SWA 128；单次前向并行产出 5 个草稿位置的 base logits
Markov head轻量建模草稿 token 之间的依赖
Confidence head预测逐位置条件接受概率 → 估计前缀存活概率
调度器结合存活概率与 profiled 引擎吞吐曲线，按当前系统负载动态选验证长度 → 最大化系统级 token 吞吐
与 V3 MTP 的区别MTP 随 backbone 全程联合训练；DSpark 在预训练后独立阶段训练（backbone 冻结），后训练期共训但不把 DSpark 梯度回传 backbone → 始终对齐演化中的策略，同时加速在线服务与 RL/OPD rollout
2.4.4 FP4 Main KV Cache（主 KV 缓存 FP4 化）▾
动机V4 已对 indexer Q/K 用 QAT FP4（加速索引计算）；本次把 QAT 扩展到主 KV（目标：省存储而非加速 GEMM）
格式：OCP 标准 MXFP4E2M1 数值 + 每 16 通道 1 个 E4M3 scale（追随 NVFP4 但省略其二级全局 scale）
关键技巧注意力前先反量化 → 无需原生 FP4 矩阵乘支持 → 硬件可移植性好
为何可省略全局 scale（精度论证）格式量程 448×6=2688；KV latent 量级界：RMS 后 512 通道 L2 范数 ≤ √512 ≈ 22.6，RoPE 保范数；训练观测最大幅值约 10 → 无精度损失
量化位置与折衷QAT 于后训练引入；RoPE 之后量化（之前量化仅边际收益且增加 decode 开销）；SWA KV 保持 FP8（对量化敏感）；相比 V4 的 FP8 主 KV，存储 近乎减半（HBM 与 SSD 皆是）
2.5 Optimization（训练优化）▾
head-wise MuonQ 权重按头拆分后再应用 Muon → 每头独立 preconditioner，更好处理头间异质性（GLM 5 / Kimi-K3 亦有实证）
Sinkhorn 平衡更新（Engram 表 / embedding / prediction head）▾
动机Adam 对这些超大参数矩阵的优化器状态内存不可接受
流程（Algorithm 1）Nesterov momentum → Sinkhorn 交替行列归一（近似均衡更新矩阵的行列 RMS；掩码近零行）→ √n 缩放（单位行 ℓ2 → 单位行 RMS）→ 学习率校正 γ=0.18（贴近 Moonlight 的 0.2）使更新幅度匹配 Adam
关系与 Adafactor、Adam-mini 同属利用矩阵轴结构的优化器族
基础配置（按参数类别分配优化器）▾
AdamWnorm 层权重与其它非矩阵参数（bias、scale）
Muonbackbone 线性层权重、Engram 投影层、视觉-语言 projector
head-wise MuonQ 与 K 权重
正则decoupled weight decay + Nesterov；norm 层有权重衰减，bias/scale 无；Sinkhorn 更新无权重衰减
Vision encoder 调度预训练期冻结直到 LR decay 阶段（最终 norm 层与 VL projector 一直可训）；LR decay 开始时解冻、以更小学习率与 LLM 联合训练
